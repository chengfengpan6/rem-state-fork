# Archived real-model smoke

This directory contains the completed 342-response run requested from
`gpt-5.6-luna` through the ChatGPT-authenticated official CLI.

- `manifest.json`: actual scope, model request, timestamps and completion.
- `calls.jsonl`: full explicit task inputs, schemas, real responses and transport metadata.
- `events.jsonl`: ordered execution including branch, measurement and update events.
- `checkpoint.json`: common formation, initial forks and final states.
- `tapes.json`: researcher-side synthetic events, including later truths.
- `summary.json`: descriptive scores, paired differences and terminal status.
- `verification.json`: 5,018 saved-record checks, all passed.
- `provenance.json`: live and replay code versions, raw-file hashes and setup-call disclosure.

The first offline replay failed on a Windows file replacement; its failure record
is retained in the adjacent `verification_attempts` directory. The correction
did not request new model responses or alter the live evidence. A new strict
replay consumed all 342 responses and reproduced the substantive artifacts.

There is one shared history, not 342 independent experimental observations.
The final map update has no subsequent live prediction in this short run.
All source signals happened to be correct in formation; no strict initial
ranking reversal occurred. These records must not be used to claim a validated
mechanism, powered treatment effect, or parameter recovery.
