What this release establishes

A bounded run completed on the requested gpt-5.6-luna model via Codex CLI 0.162.0-alpha.17.2 and ChatGPT login. Shared formation used 30 calls; twelve continuations used 189. There were no errors or retries. The CLI did not expose a served-model version, so identical weights are not claimed.

This is engineering evidence, not an experimental finding. It contains one history, three formation rounds and one future round. The visible P/E change is in context Y; the actual future case is X. It does not validate within-context distortion sensitivity, population effects or post-update correction.

What the study still needs

Coverage of changed contexts, repeated responses across independent histories, a demonstrated history-to-H formation link, decisions after map updates, and justified precision or power. Recall, reported belief, cue sensitivity and judgment are different measurements. One A/A pair is not a noise distribution. Architecture comparisons change multiple features; a shared table does not by itself establish a social mechanism.
