# Release notes for 30 October 2026

This is a verification and documentation revision, with no new model calls and
no changes to historical experimental records or prespecified analysis.

## Changes

- Limit optional replay tolerance to explicitly identified recomputed loss
  fields, at a finite absolute maximum of 1e-12; default remains strict.
- Preserve strict comparisons of experimental inputs, predictions, map cells,
  schema, types, identifiers and messages. Bind state hashes to actual source
  states and explain accepted score-only changes by path.
- Persist consistent replay-validation metadata in root and history summaries
  and retain tolerance details in replay traces.
- Check explicit prompts independently of the historical `is_live` flag and
  check raw/parsed responses and model metadata where supplied.
- Add original Claude/Gemini archives and source manifests; keep historical
  adapter bytes separately with documented limitations.
- Add independent response-level arithmetic and a portable all-archive offline
  review command. No SDK, API key or fresh model execution is needed.
- Correct historical document banners and present all three bounded results.

The code and raw records, supplied original receipts and newly generated
validation receipts are separate evidence layers. Current receipts are under
`validation/2026-10-30`; earlier Mac receipts do not establish that the new
verifier has been executed on a Mac. Re-run the review command on the actual
review environment and retain its receipt.

## Preserved scientific boundaries

P−E tests planted content under matched researcher attribution. H−E combines
content and provenance, and its sign differs by route. The three results are
not independent implementations or a factorial test of model-versus-route
effects. Short selected histories, fixed profiles, opaque provider randomness,
and incomplete historical API-attempt metadata remain limits. Future deep
histories, feedback trajectories, readout probes and architecture comparisons
are proposals, not completed experiments.

## Reproduction

From a clean checkout, install `requirements-lock.txt`, then run:

```sh
python tools/review_all_archives.py --output runs/complete-offline-review
```

Do not edit evidence to make a strict platform mismatch disappear. The tool
records strict results, requires explicit bounded verification to succeed,
replays retained responses, verifies replay outputs, and re-derives statistics.
Historical adapters are not imported by this path.
